# Changelog

## 0.1.0 - 2026-09-03

- Initial public release of the adapter for `elementareteilchen/bayernatlas-fluid`.
- maps2 record conversion, per-content renderer choice and category layers.
- Existing maps2 AJAX info windows with translated public errors.
- Native maps2 consent, shared permission and session-cookie settings.
- TYPO3 13.4/maps2 12.2 and TYPO3 14.3/maps2 13.1 test matrix.
- No demo extension or sample records in the published package.

The upstream web component remains in beta. See `Documentation/Deployment.md`
for domain approval and outstanding browser acceptance.
